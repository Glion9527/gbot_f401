# 二手 ICM-20948 + BMP280（微雪 10 DOF IMU (D)）验收测试

> 目标：在不把问题混进小车固件的前提下，用 10–30 分钟判断这块二手模块
> **能不能用、准不准、哪一路坏了**。

> **TL;DR（15 分钟）**：断电接 4 根线（3V3/GND/PB9/PB8）→ CubeIDE Build+Run →
> 串口 115200 看 `WHO_AM_I=0xEA` / `AK09916 WIA=0x09` / `BMP ID=0x58` →
> 模块六个面轮流朝下，看 `|a|` 是否都是 1.000 g → 完事。

## 0. 先把型号对齐

| 项 | 实际值 | 说明 |
| --- | --- | --- |
| 模块 | 微雪 10 DOF IMU Sensor (D) | “10 轴”= 3 加速度 + 3 陀螺 + 3 磁力计 + 1 气压 |
| 主芯片 | **ICM-20948** | 不是 ICM-20849 / ICM-20949，搜索资料时注意 |
| 气压芯片 | BMP280 | 与 ICM 共用一条 I2C |
| 磁力计 | AK09916 | 封装在 ICM-20948 内部，**不在主总线上** |
| 接口 | 6 pin：VCC GND SDA SCL INT FSYNC | 只用前 4 根即可，INT/FSYNC 悬空 |
| 供电 | 3.3–5.5 V（板载 RT9193 LDO + 电平转换） | **建议 3.3 V**，5 V 时总线电平会被拉到 5 V |

I2C 地址（7 位）：

| 器件 | 地址 | 备注 |
| --- | --- | --- |
| ICM-20948 | **0x68** | AD0=0；若为 0x69 说明 AD0 被拉高 |
| BMP280 | **0x76 / 0x77** | 由 SDO 电平决定；**这块微雪板实测 0x77**，探针会自动适配 |
| 磁力计 | **0x0C** | 需先置 ICM 的 `INT_PIN_CFG(0x0F)` bit1 = 1（旁路）才可见；WIA 0x09/0x0C=AK09916/09918，**0x48=AK8963** |

## 1. 二手模块最常见的四种坏法

按出现概率排序，验收时优先排除：

1. **磁力计 AK09916 坏**（ESD、强磁、热风拆焊）→ 模块变成“6 轴”，ICM/气压都正常，只有 0x0C 不应答。
2. **排针/焊盘虚焊**（拆装受力）→ 时好时坏、按压板子才通。
3. **LDO 或电平转换损坏**（曾 5 V 反接/超压）→ 上电电流异常、3.3 V 轨不对、总线读全 0xFF。
4. **芯片被 ESD 打穿 I2C 引脚** → 0x68 完全无应答（这种基本判死）。

另外“曾被强磁化”不算坏，只是磁力计零偏大，可以软件标定。

## 2. 四级验证流程

> 手边有 Arduino / 树莓派 / USB-I2C 小板的话，直接跑官方例程比接 STM32 更快，下面的判据完全通用。

### L0 不上电检查（5 分钟）

- 目视：芯片有无裂纹/鼓包、焊点是否发黑、有没有飞线维修痕迹、排针是否歪。
- 万用表：
  - VCC–GND 不能短路（几欧姆 = 坏）；
  - SDA/SCL 对 VCC 应有 2–10 kΩ（板载上拉），对 GND 不能短路。
- 上 3.3 V 测电流：正常 **2–5 mA** 量级（陀螺 1.23 mA + 加速度 69 µA + 磁 90 µA + 数字电路；带电源指示灯的模块再加几 mA）。
  - < 0.5 mA：没起来/供电断；> 30 mA：有短路，立刻断电。

### L1 总线与身份（10 分钟，性价比最高）

1. 扫描：**0x68 必须在，BMP280 在 0x76 或 0x77**（这块板是 0x77）。
   - 只有 0x68 → BMP280 或其焊点坏；
   - 只有 0x76 → ICM 坏，直接退货；
   - 都没有 → 接线/供电/上拉问题，先别怀疑模块。
2. `ICM 0x00 WHO_AM_I` = **0xEA**；`BMP280 0xD0` = **0x58**。
3. 写读回：`ICM 0x06 PWR_MGMT_1` 写 `0x01` 再读，应回 `0x01`（复位值 0x41 = 睡眠中）。
4. 磁力计：置 `0x0F |= 0x02` 后，`0x0C` 的 `WIA1(0x00)` = **0x09**。

> 到这一步就能给出“能不能用”的结论：三个 ID 全对 = 电气与通信层面基本健康。

### L2 静态物理量（15 分钟，判断“准不准”）

**加速度六面法（最快的三轴全好证明）**：把模块的 +X/+Y/+Z/−X/−Y/−Z 依次朝下，每个面停 3–5 s。
合格表现：每次只有一个轴接近 ±1 g，其余接近 0，且 **|a| 始终在 0.98–1.02 g**。
某轴读数恒定不变 → 该轴 MEMS 卡死或数据解析错（先排除字节序问题）。

**陀螺**：静止放 60 s，采 100–200 Hz。
- 均值即零偏（后面做姿态解算要减掉），合格 < 2 dps；
- 标准差即噪声，合格 < 0.3 dps；
- 再用手转 90°（用手机水平仪/量角器辅助），对角速度积分，误差 < 5% 说明刻度正常。

**磁力计**：木桌上远离电脑/音箱/手机/电机，读三轴并算模长。
- 地磁场总强度 25–65 µT，国内多数地区 **45–55 µT**；
- 转动模块，三轴都应随方向变化；
- 拿一块磁铁靠近再拿远，读数应能回到原来的量级（回不去 = 被磁化，可标定但精度下降）。

**气压/温度**：补偿后的气压与当地天气 App 或手机气压计比，**±3 hPa** 以内；温度与室温差 3 ℃ 以内（BMP280 自热小）。
哈一口气或靠近空调出风口，气压应有可重复的几百 Pa 变化。

### L3 动态与稳定性（30 分钟，可选）

- 敲桌面：加速度出现尖峰、陀螺有响应 → 内部无松动。
- 温漂：吹风机低温档从 25 ℃ 吹到 45 ℃，零偏变化 < 0.2 dps/10 ℃ 可接受。
- 长稳：静止 30 min，零偏漂移 < 0.5 dps（对轮式里程计足够）。
- 一致性：同一动作下与手机/第二块 IMU 对比趋势。

## 3. 判据表

| 项目 | 测法 | 合格 | 可疑（可标定/降级用） | 判坏 |
| --- | --- | --- | --- | --- |
| I2C 应答 | 扫描 | 0x68 + 0x76 + 0x0C | 缺 0x0C（只剩 6 轴） | 0x68 不应答 |
| ICM ID | 0x00 | 0xEA | — | 其它值 |
| BMP ID | 0xD0（0x76/0x77） | 0x58 | — | 0x00 / 0xFF |
| 加速度模长 | 六面静止 | 0.98–1.02 g，六面一致 | 0.95–0.98 / 1.02–1.05 | 偏差 > 5%，或某轴恒定 |
| 加速度零偏 | 水平放置 | 每轴 < 50 mg | 50–150 mg | > 200 mg 或跳变 |
| 陀螺零偏 | 静止 60 s 均值 | < 2 dps | 2–5 dps（规格上限量级） | > 10 dps 或持续漂移 |
| 陀螺噪声 | 静止标准差 | < 0.3 dps | 0.3–1.0 dps | 毛刺/跳点/某轴恒定 |
| 陀螺刻度 | 转 90° 积分 | 误差 < 5% | 5–10% | > 10% |
| 磁力计 ID | 0x0C 的 0x00 | 0x09 / 0x0C / 0x48 都算有芯片 | — | 无应答 |
| 磁力计模长 | 远离铁磁 | 45–55 µT（国内） | 偏移大但可标定 | 0 / 满量程 / 不变化 |
| 磁力计随动 | 转动模块 | 三轴都变化 | 某轴迟钝 | 某轴不动 |
| 气压 | 与当地比 | ±3 hPa | ±5 hPa | 不变 / 0xFFFFFF |
| 温度 | 室温 | ±3 ℃ | ±5 ℃ | 固定值 |
| 电流 | 3.3 V | 2–6 mA | 6–15 mA | > 30 mA 或 < 0.5 mA |

**一句话结论**：三个 ID 全对 + 六面 |a| 在 1.000±0.02 g + 静止陀螺 < 2 dps + 磁场 ~50 µT 且随动 + 气压与当地差 < 3 hPa ⇒ 这块二手可以放心用。

## 4. 固件：验证探针与正式驱动

### 4.0 验证探针（已归档，不参与编译）

验收阶段的探针留在 `docs/probe/icm20948_probe.c`，只作参考；工程里已换成正式驱动。
它上电打印身份、磁力计寄存器 dump、I2C 扫描，之后每 200 ms 打一行原始数据。

接线（断电接线，PB8/PB9 空闲）：

| 模块 | F401RE | 说明 |
| --- | --- | --- |
| VCC | 3V3 | 不要接 5V，省得纠结电平 |
| GND | GND | 一定共地 |
| SDA | **PB9** | I2C1_SDA，AF4 |
| SCL | **PB8** | I2C1_SCL，AF4 |
| INT | 不接 | 轮询方式用不到 |
| FSYNC | 不接 | 保持悬空 |

### 4.1 正式驱动 `icm20948.c/h`

| 文件 | 作用 |
| --- | --- |
| `Core/Inc/icm20948.h` | `icm_data_t` 数据结构和 API |
| `Core/Src/icm20948.c` | I2C1 初始化、ICM 配置、磁力计、BMP280 补偿、互补滤波 |

| API | 说明 |
| --- | --- |
| `ICM20948_Init()` | 复位、±4 g / ±500 dps、DLPF 50 Hz、开磁力计旁路、0.8 s 陀螺零偏标定（**需静止**） |
| `ICM20948_Read(&imu)` | 读一次并更新 `roll/pitch/yaw`、气压、高度、温度 |
| `ICM20948_ZeroYaw()` | 把当前朝向记为 0°，上车摆正后调用 |
| `ICM20948_CalibrateGyro(ms)` | 重新标定零偏 |
| `ICM20948_MagCalStart()` / `ICM20948_MagCalFinish(off)` | 磁力计硬铁标定：转几圈后取偏置 |

主循环 20 ms 读一次、100 ms 打一行（`IMU_DRIVER_ENABLE` 改 0 可整体关闭）：

```text
IMU r=1.2 p=-3.4 y=125.6 | 1010.6 hPa 22.4 C | B=50.1 uT
```

行首不带 `@`，Mac 网关会忽略，不影响现有遥控协议。

## 4.2 本模块实测记录（2026-11，这块二手）

| 项 | 实测 | 结论 |
| --- | --- | --- |
| ICM-20948 WHO_AM_I | 0xEA | 六轴内核应答正常 |
| 加速度静止 | 模长 0.996–1.005 g，三轴稳定 | 加速度计正常 |
| 陀螺静止 | 约 0.6–2 dps 零偏，抖动小 | 正常，做姿态前需减零偏 |
| BMP280 | 地址 **0x77**（不是 0x76），ID 0x58 | 气压计正常 |
| 气压/温度 | 1010.6 hPa / 22.6 ℃，10 s 内波动 <0.2 hPa | 正常 |
| 磁力计 WIA1 / WIA2 | **0x48 / 0x09** | **非原装（兼容片）**：WIA1 不是 AK09916 的 0x09，WIA2=0x09 且寄存器是 AK09916 架构 |
| 磁力计数据 | 磁场模长 ≈ 49 µT，随转动变化 | 磁力计**正常**（注意数据低字节在前） |
| 磁力计寄存器 | `31:08` 可写可读，`0A:FF`（无 AK8963 的 CNTL1），数据区在 0x11 | 按 **AK09916 路径**驱动，不能按 AK8963 驱动 |

含义：这块的**六轴内核是 ICM-20948 兼容的，磁力计是 AK09916 兼容片**（不是原装 TDK 器件）。四路都正常，可以作为 9 轴 + 气压使用。
注意：BMP280 在 0x77 只是 SDO 接高的正常设计，**不是缺陷**；真正异常的是磁力计 WIA1=0x48 而不是 0x09。

- 磁力计是**AK09916 兼容片**（WIA1=0x48、WIA2=0x09），寄存器按 AK09916 驱动即可；认死 WIA==0x09 的官方/第三方库会初始化失败；
- 磁力计数据是**低字节在前**，不能和 ICM 加速度/陀螺共用大端拼接函数；
- 实测磁场模长 49.8–51.8 µT，稳定。

**验收结论：四路全部通过**（加速度 1.000 g、陀螺零偏约 1–2 dps、磁场 ~50 µT、气压 1010.6 hPa）。

## 5. 常见“假故障”（别急着判模块死刑）

1. **0x68 扫不到**：SDA/SCL 接反、杜邦线接触不良、模块被 5 V 打坏 LDO、地址其实是 0x69、上拉缺失。
2. **扫到但读 0x00/0xFF**：没退出 sleep（`PWR_MGMT_1` 复位值 0x41）；I2C 读写时序错（要 repeated start）；供电不足。
3. **配置写了没用**：ICM-20948 的配置寄存器在 **bank 2**（`GYRO_CONFIG_1`=0x01、`ACCEL_CONFIG`=0x14），bank 0 的 0x14 是别的寄存器。照 MPU-9250 的地址写必然不生效。切 bank：`0x7F` 写 `0x00/0x10/0x20/0x30`。
4. **磁力计读不到**：没开旁路；或开了旁路但 `USER_CTRL.I2C_MST_EN=1`；`CNTL2(0x31)` 没置测量模式（0x08 = 100 Hz 连续）。
5. **磁力计数据不刷新**：AK09916 读完 0x11–0x16 后必须读 `ST2(0x18)`（一次读 0x10 起 9 字节最省事），否则数据寄存器不更新。
6. **BMP280 读数离谱**：没做校准补偿（必须用 0x88 起 24 字节系数 + Bosch 算法）；把 BME280（ID 0x60）当 BMP280。
7. **磁力计读数总是 256 的整数倍**：高低字节读反了。AK09916/AK8963 的数据寄存器是低字节在前（HXL 在 0x11），ICM 的加速度/陀螺是高字节在前，两者不能共用同一个拼字节函数。
8. **偶发 HAL_BUSY/HAL_TIMEOUT**：线太长、上拉太弱、和电机线并行、TB6612 换向地弹。降速到 100 kHz、加 4.7 kΩ 外部上拉、缩短杜邦线。

## 6. 装到小车上之前

- I2C 走 PB8/PB9，400 kHz 够用；读数用 burst（0x2D 起一次 12 字节 = 加速度 + 陀螺）。
- 电源：模块 3.3 V 单独走线，加 100 µF + 0.1 µF 去耦；四路电机换向时地弹明显，I2C 线远离电机线。
- **磁力计在四轮小车上只能做慢修正**：电机磁铁和电流产生的磁场可达几十 µT，跑起来 yaw 主要靠陀螺积分，磁力计只在静止/直线段做慢速修正；实在干扰大就放弃磁力计，用编码器 + 陀螺。
- 采样 100–200 Hz，连续采样时别忘了 `PWR_MGMT_1` 自动时钟，量程按用途选（±4 g / ±500 dps 比较通用）。
